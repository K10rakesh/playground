# 🛝 Playground

A personal sandbox for experimenting with new technologies, testing ideas, and building quick prototypes.

This repository contains small projects, code snippets, proofs of concept, and experiments that don't belong in a dedicated repository but are worth exploring.

## 📂 Structure

```
playground/
├── express-validator/
└── ...
```

Each folder is independent and may contain its own documentation and setup instructions.

## 🎯 Purpose

This repository is used to:

- Learn new technologies
- Test APIs and libraries
- Explore framework features
- Try coding ideas before using them in real projects
- Store reusable snippets
- Practice algorithms and language features

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/playground.git
cd playground
```

Navigate to the experiment you want to run and follow the instructions inside that directory.

## 📌 Notes

- Experiments may be incomplete or intentionally minimal.
- Code quality and structure may vary depending on the purpose of the experiment.
- Some folders may require additional dependencies or environment variables.
